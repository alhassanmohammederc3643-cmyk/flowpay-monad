A working x402 payment route on Monad testnet. An agent receives an HTTP 402, signs a test USDC authorization, and retries. The facilitator settles directly from buyer to seller and returns the chain receipt.

Watch a test payment settle

This demo pays 0.001 test USDC for a JSON response. Test tokens have no real-world value. The buyer signs; the facilitator pays test MON gas.

The route
  1. Request /api/quote: HTTP 402 with exact payment terms.
  2. Sign EIP-3009 for the named recipient and amount.
  3. Verify signature, balance, expiry and unused nonce.
  4. Settle test USDC on Monad, chain ID 10143.
  5. Return the result only after a successful receipt.
